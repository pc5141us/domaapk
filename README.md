## 🌟 كيفية الاستخدام خطوة بخطوة

1. افتح المحادثة مع البوت: [**@Webhookcbot**](https://t.me/Webhookcbot).
2. أرسل **التوكن الخص ببوتك** (من BotFather).
3. سيتأكد البوت من التوكن ويطلب منك **رفع ملف الكود الخص بك** (`.js`, `.php`, `.json`, `.txt`).
4. قم بإرفاق ورفع الملف داخل المحادثة.
5. يقوم البوت بقراءة ملفك واستضافته على Vercel، وتوليد رابط الويب هوك الديناميكي:
   `https://domaapk.vercel.app/api/dynamic-webhook?botId=YOUR_BOT_ID`
   وتفعيله فورياً على تليجرام!
