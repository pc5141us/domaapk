## 🌟 كيفية استخدام البوت لربط بوتك الآخر

1. افتح المحادثة مع البوت: [**@Webhookcbot**](https://t.me/Webhookcbot).
2. اضغط على **➕ ربط ويب هوك لبوت آخر** (أو أرسل التوكن المباشر للبوت).
3. ستقوم الأداة بالتحقق من التوكن واستخراج معلومات البوت الخاص بك (`@YourBot`).
4. أرسل **رابط الويب هوك (URL)** الخص بك (مثل `https://my-app.vercel.app/api/webhook`) أو ارفع ملف الكود الخص بك.
5. ستقوم الأداة فوراً بتعيين الويب هوك للبوت الآخر وإظهار النتيجة كاملة بجميع التفاصيل!
