# 🤖 صانع ومستضيف الويب هوك الدائم لبوتات تليجرام (Telegram Cloud-Backed Webhook Creator)

حل متكامل ومستدام 100% يتيح للمستخدمين **رفع ملفات كود بوتاتهم وسورس كود التطبيقات**، ويقوم البوت **بحفظ الملفات بشكل دائم على سحابة تليجرام واستضافتها على Vercel Serverless بدون حاجة لقواعد بيانات خارجية، وتفعيل الويب هوك تلقائياً**!

---

## 📌 مميزات نظام الحفظ الدائم (Persistent Storage)
1. **لا يضيع الملف أبداً:** يتم تخزين ملفات الكود المرفوعة على سحابة تليجرام الدائمة (Telegram Cloud).
2. **رابط ويب هوك ذكي ومشفر:**
   `https://domaapk.vercel.app/api/dynamic-webhook?token=BOT_TOKEN&file_id=FILE_ID`
3. **يعمل 24/7 على Vercel:** بدون استهلاك سيرفرات دائماً، مجاني ومضمون 100%.

---

## 🌟 كيفية الاستخدام خطوة بخطوة

1. افتح المحادثة مع البوت: [**@Webhookcbot**](https://t.me/Webhookcbot).
2. أرسل **التوكن الخص ببوتك** (من BotFather).
3. قم **برفع ملف الكود الخص بك** (`.js`, `.php`, `.json`, `.txt`).
4. يقوم البوت بحفظ الملف تلقائياً على سحابة تليجرام المباشرة وتوليد رابط الويب هوك الدائم وتفعيله فوراً على بوتك!

---

ارفع الملفات إلى GitHub:

git add .
