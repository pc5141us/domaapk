# 🤖 بوت إدارة الويب هوك (Arabic Webhook Bot for Vercel)

بوت تليجرام عربي بالكامل مصمم ومعد خصيصاً للرفع والتشغيل على منصة **Vercel (Serverless Functions)** ولإدارة وربط وفحص الويب هوك (Webhook) لبوتات تليجرام بكل سهولة.

---

## 📌 معلومات البوت المسبقة
- **اسم البوت:** ويب هوك (`Webhookcbot`)
- **التوكن:** `5777908472:AAHoyjbO-SouHb8Mw3aYl51zdTKpj3DQuog`

---

## ✨ المميزات الرئيسية
1. **عربي بالكامل:** جميع الواجهات والأوامر والرسائل والتنبيهات مكتوبة بلغة عربية سلسة ومنسقة.
2. **أزرار تفاعلية (Inline Keyboards):** قوائم تفاعلية سريعة ومريحة في الاستخدام.
3. **إدارة الويب هوك الشاملة:**
   - ℹ️ **فحص الويب هوك الحالي:** استعلام دقيق عن الرابط وعدد الرسائل المعلقة والتأخيرات والأخطاء.
   - 🔗 **ربط ويب هوك جديد:** إمكانية إرسال أي رابط وسيقوم البوت بتفعيله فوراً مع Telegram API.
   - 🗑️ **حذف الويب هوك:** إلغاء الويب هوك للعودة لنظام البولينج (Polling).
4. **تكامل كامل مع Vercel:**
   - دعم **Serverless Functions** لعدم استهلاك سيرفرات دائماً (مجاني 100%).
   - رابط تفعيل سريع `api/set-webhook` لتنشيط البوت بضغطة زر واحدة.
   - لوحة ويب عربية أنيقة لعرض حالة البوت والويب هوك من المتصفح مباشرة.

## 🚀 كيفية النشر على موقع Vercel (فيرتيكال)

### الخطوة 1: الرفع إلى GitHub
قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub وارفِع كود هذا المشروع إليه:
```bash
git init
git add .
git commit -m "المشروع الأول للبوت العربي"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

### الخطوة 2: الربط بمنصة Vercel
1. سجّل الدخول إلى موقع [Vercel.com](https://vercel.com).
2. انقر على **Add New...** ثم **Project**.
3. اختر مستودع GitHub الخاص بك واضغط على **Import**.

### الخطوة 3: إضافة المتغيرات البيئية (Environment Variables)
في صفحة الإعدادات قبل النشر، افتح قسم **Environment Variables** وأضف:
- **Key:** `BOT_TOKEN`
- **Value:** `5777908472:AAHoyjbO-SouHb8Mw3aYl51zdTKpj3DQuog`

ثم انقر على **Deploy**.

### الخطوة 4: تفعيل الويب هوك بنقرة واحدة ⚡
بعد انتهاء عملية النشر، ستحصل على رابط للمشروع (مثال: `https://my-bot.vercel.app`).
لتفعيل الويب هوك، قم بفتح الرابط التالي في متصفحك مرة واحدة فقط:
```text
https://my-bot.vercel.app/api/set-webhook
```
ستظهر لك رسالة تأكيد بالنجاح `✅ تم ربط الويب هوك بنجاح على Vercel!`.


## 💬 الأوامر المتاحة داخل البوت
- `/start` - البداية وعرض القائمة الرئيسية.
- `/info` - فحص وتفاصيل الويب هوك.
- `/set <URL>` - ربط ويب هوك جديد مباشرة.
- `/delete` - حذف وتجميد الويب هوك.
- `/botinfo` - معلومات ومعرف البوت.
- `/help` - دليل التعليمات والأوامر.
